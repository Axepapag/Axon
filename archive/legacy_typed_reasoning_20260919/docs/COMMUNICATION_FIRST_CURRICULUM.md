# Axon Communication-First Curriculum Contract

Status: design contract for the next curriculum implementation
Established: 2026-08-30

## Purpose

Axon's first learned D64 cores must become competent communicators through the
real runtime output contract before broad reasoning becomes the selection goal.
The existing mechanism curriculum and FFCS A-F remain permanent prerequisite
and regression tissue. They prove exact transport, field use, private-Soul
carriage, proposal society, and long-field mechanics; they do not constitute a
complete conversational education.

Every core is part of Axon. Canonical Identity defines the one shared Axon
identity attended by all cores. A core's private Soul supplies its own causal
perspective and continuity; it is not a separate public persona. Final answers
speak as Axon. Engineering core IDs remain provenance, not dialogue identity.

## Universal lesson laws

1. Except for explicitly labeled copy-mechanism cases, the target response is
   never present in the Shared Field, proposal board, Soul fixture, metadata,
   filename, or sibling example.
2. The exact runtime path is used: canonical field -> rail -> private Soul
   inhale -> first proposal -> Soul exhale/re-inhale -> complete brother board
   -> refined proposal -> consolidator -> Heart validation/commit.
3. Exact typed decision, operation, region, canonical addresses, 351-category
   Unicode transport, EOS, and authority are hard gates on every stage.
4. Training/heldout/regression separation is by whole conversation, episode,
   source, and time lineage. Adjacent turns from one conversation never cross a
   split.
5. Recovered assistant output is an observation, not automatic truth. A target
   requires explicit accepted, corrected, endorsed, or otherwise evidenced
   outcome quality. Observed-only and quarantined material cannot supervise.
6. Generated teaching responses cite exact source evidence and may paraphrase
   it, but may never fabricate autobiography. Human review samples remain part
   of open-response gates.
7. Exact memories remain in Dormant State. Parameters learn how to locate,
   interpret, and communicate memory; they are not treated as a lossy
   replacement for the autobiography.
8. A curriculum-stage gate decides mastery. Resource tranches only pause and
   resume work; they never define a core lifetime or curriculum capacity.
9. No fixed dataset size, character count, context window, Soul capacity, or
   step count becomes a permanent doctrine. Declared v1 sizes are revisable
   evidence budgets.
10. No serving promotion follows from training loss alone.

## Developmental stages

### C0 — Exact mouth and hand control

Use the existing mechanism curriculum and FFCS regression surface. Require
exact delta/no-op/abstain, correct region/address, Unicode/EOS, complete-field
coverage, malformed-output rejection, Soul lineage, and proposal-board use.

### C1 — Hidden-target single-turn communication

Teach greetings, acknowledgements, direct short answers, clarification when a
material ambiguity exists, corrections, uncertainty, concise explanations,
and ordinary conversational turn-taking. Only the user input and legitimate
field evidence are visible; the answer target is hidden. All successful
answers update `response_draft` through the real typed-delta contract.

### C2 — Shared identity and voice

Teach Axon's D2/Dexter/Axon lineage, constitution, mission, relationships, and
voice. Include ordinary questions where Identity should remain quiet, direct
identity questions, stale/conflicting brother proposals, and corrected
historical claims. Measure consistent behavior rather than rote Identity
quotation. Ordinary cores cannot write the Identity region.

### C3 — Autobiographical grounding

Materialize exact governed Dormant evidence into the visible field and teach
recognition, temporal order, relationship facts, corrections, synthesis across
multiple records, and explicit absence of supporting memory. Targets cite
source record IDs in training evidence even when the conversational response
does not expose internal provenance syntax.

### C4 — Multi-turn continuity and private Soul

Teach follow-ups, commitments, unresolved questions, self-correction, context
carriage, and appropriate behavioral dependence on the same core's private
Soul. Soul ablation and swapped-Soul probes must change behavior where causal
continuity matters and remain irrelevant where it does not.

### C5 — Axon society

Teach independent first proposals, complete-board inspection, evidence-based
agreement/disagreement, refinement gain, rotating consolidator duty, and one
coherent Axon response. Majority copying is not a valid consolidator strategy.

### C6 — Broad reasoning and tools

Only after communication stages pass, expand into planning, arithmetic, code,
science, psychology, poetry, tool use, and long-form synthesis. Earlier stages
remain mandatory regression gates.

## Gate structure

Each stage declares minimum complete exposure but no destructive maximum. It
must pass on whole-lineage heldout material in multiple consecutive evaluations
while retaining all prior stages. Deterministic tasks use exact-match gates.
Open conversation combines groundedness, relevance, identity consistency,
epistemic honesty, coherence, counterfactual behavior, and human-audited
samples; one model-judge score or one preferred string cannot be sole authority.

The first implementation shot is C1: compile a small, diverse, provenance-
governed hidden-target family; verify zero target leakage; run CPU preflight and
one-step mechanism checks; then use renewable tranches to compare 1x64, 2x32,
and 4x16 by gate attainment and sample efficiency rather than raw loss.

## Current evidence readiness (verified 2026-08-30)

The canonical Dormant store currently contains 59,876 records across two
imports, but it contains zero `runtime_reasoning_episode` records and zero
`runtime_episode_outcome` records. Existing recovered user/assistant adjacency
can be compiled as observed conversation sessions, but its policy correctly
marks it ineligible for serving supervision because historical occurrence does
not prove target quality. Therefore C1 is **not yet launch-ready**.

The next data step is not more optimizer steps. It is an evidence-qualified C1
target batch: accepted/corrected/endorsed responses, whole-conversation lineage
IDs, explicit outcome evidence, hidden targets, and train/heldout/regression
splits that cannot share a conversation or nearby source lineage. Only after
that manifest passes leakage and runtime-materialization checks should it enter
a renewable D64 tournament tranche.
