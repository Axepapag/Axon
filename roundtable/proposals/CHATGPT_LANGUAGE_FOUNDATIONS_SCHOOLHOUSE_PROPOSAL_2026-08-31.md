## 1. Executive position

Jeff's conclusion is correct: the body had to be built before the child could be taught inside it.

Axon now has enough primitive-but-functional permanent anatomy to justify a new developmental step:

- exact Unicode canonical state over the frozen additive 16D transport;
- a complete Shared Field with masks, regions, provenance and coverage law;
- the exact D64 compiler shared by runtime and training;
- a living D64 core with load-bearing private Soul, page-by-page complete-field reading, typed output, categorical Unicode transport emission and fail-closed malformed output;
- FIRST -> REFINED -> CONSOLIDATED circulation and proposal boards;
- real sequential ticks with canonical successors and Soul serialization/re-inhale;
- Trainer authority, immutable curricula, parameter/Soul bundles, checkpoints, evaluation, renewable resource tranches and rollback lineage;
- FFCS as an anatomy/transport/Soul/society school;
- C1 as the first hidden-target communication experiment.

The current missing bridge is linguistic development. C1 asks a from-scratch D64 core to go from exact transport and body mechanics directly into full conversational responses. That is a large developmental jump. I propose inserting a permanent **Language Foundations Schoolhouse** between substrate mechanics and broad conversation/reasoning.

The central idea is simple:

```text
exact 16D substrate
    -> character familiarity
    -> spelling and punctuation
    -> words and vocabulary
    -> morphology
    -> grammar
    -> sentence transformations
    -> reading comprehension
    -> short composition
    -> dialogue
    -> Axon-domain language
    -> engineering/tool/reasoning curricula
```

This must NOT become a second model, tokenizer, pretraining pipeline, special training-only context path, or external-language adapter. The actual brother must learn inside the body he will use in service.

Every lesson must enter as canonical/derived textual surfaces, compile through the same permanent rail boundary, be read with the same Soul-conditioned complete-field path, and emit through the same typed categorical transport surface used by runtime.

## 2. Non-negotiable physical contract: teach the actual organism

### 2.1 Lesson ingress

A Language School lesson should be built as a normal `SharedFieldSnapshot` (or an existing runtime-faithful curriculum case wrapping one), for example:

```text
IDENTITY:
    canonical Axon Identity

CONVERSATION_HISTORY:
    optional prior material

USER_INPUT:
    lesson prompt / question / exercise

CORTEX:
    definitions, facts, examples, reading passage, word bank, grammar evidence

SCRATCH:
    empty or exact prior canonical scratch when the curriculum genuinely requires it

RESPONSE_DRAFT:
    empty at lesson start
```

Then:

```text
SharedFieldSnapshot
    -> D64FieldCompiler
    -> exact complete D64 rail
    -> private Soul inhale
    -> complete ordered field sweep
    -> proposal surfaces where applicable
    -> typed response-draft delta / no-op / abstain
    -> exact categorical transport
    -> Heart-compatible text/delta
    -> private Soul successor
```

Do not create `LanguageTokenBatch`, hidden word embeddings, a private tokenizer, an off-body text encoder, or a Trainer-only sequence that bypasses the Shared Field.

### 2.2 The rail truth boundary

The exact scaffold remains 16D transport truth. D64 is the current physical home rail. The current per-character D64 reader may deterministically unpack exact 16D transport cells and lift them into learned 64D neural tokens. This is acceptable and permanent specialist tissue.

The invariant is:

```text
external/canonical text -> exact typed 16D transport -> home rail -> learned neural state
```

and on output:

```text
learned neural state -> categorical transport decisions -> valid Unicode/text -> typed delta
```

The external textual surfaces must round-trip exactly. Internal activations, FFN states, attention states and opaque private Soul are neural/private and are NOT required to decode into 16D or human text.

This distinction should be explicit in all Schoolhouse documentation:

> Perception and communication remain grounded in the exact substrate. Thought is allowed to become neural.

### 2.3 Runtime fidelity

Language training may not take shortcuts that the serving core will not have:

- no future target text visible in any field region, proposal workspace, metadata, sibling case or future tick;
- no retaining a differentiable hidden state across a boundary where runtime serializes/re-inhales Soul;
- no flattening sequential lessons over an unchanged field when the runtime would create a canonical successor;
- no omitting unmasked field pages;
- no direct Trainer write into `response_draft` as an input hint;
- no bypass of authority, region, boundary, EOS, Unicode, typed-delta or malformed-output gates.

## 3. Why a schoolhouse is different from C1

C1 is useful and should remain preserved, but it currently jumps to seven communication classes such as greeting, acknowledgement, grounded answer, clarification, correction, uncertainty and turn-taking.

For a large pretrained model those are elementary. For a 64-dimensional core learning from scratch they are compound tasks involving:

- reading character sequences;
- recognizing words;
- recognizing sentence structure;
- semantic interpretation;
- maintaining context;
- selecting a conversational act;
- generating grammatically valid novel text;
- terminating the text correctly;
- authoring the correct region and delta.

The Schoolhouse decomposes those abilities into many short gates so failure becomes diagnosable.

Instead of asking only:

```text
"Hello." -> produce one good greeting
```

we first build evidence that the core can do things like:

```text
read "hello"
copy "hello"
repair "helo" -> "hello"
recognize "hello" as a greeting word
distinguish "hello" from "goodbye"
construct a simple sentence
capitalize sentence start
terminate with punctuation
select greeting intent
produce a valid greeting not necessarily equal to one memorized string
```

C1 then becomes a higher developmental layer rather than the first language lesson.

## 4. Schoolhouse architecture: developmental bands

Names below are semantic bands, not permanent code namespaces or hard ceilings. Case counts are campaign budgets, never architecture limits.

### L0 — Character and transport fluency

Purpose: make exact substrate reading/writing automatic before semantic burden increases.

Lesson types:

- exact copy of one character;
- exact copy of short character sequences;
- distinguish minimally different strings (`cat`/`cut`, `form`/`from`);
- capitalization pairs (`a`/`A`);
- whitespace, comma, period, question mark, apostrophe and quotation handling;
- exact Unicode transport cases, including non-native characters and multi-unit UTF-8 expansion;
- EOS and empty/no-op distinctions;
- insert/replace/delete at exact boundaries.

Examples:

```text
USER: Copy exactly: apple
TARGET: apple
```

```text
USER: Which spelling matches the shown word: form or from?
CORTEX: [WORD] from [/WORD]
TARGET: from
```

Gates:

- exact transport token accuracy;
- exact payload rate;
- Unicode roundtrip;
- EOS correctness;
- boundary/address correctness;
- no malformed emission.

### L1 — Spelling, capitalization and punctuation

Purpose: learn orthographic regularities as transformations rather than memorized answers.

Lesson families:

- detect misspelling;
- repair one-letter omissions/substitutions/transpositions;
- plural spelling endings;
- capitalization of sentence starts and proper names where evidence identifies them;
- terminal punctuation selection;
- apostrophes in simple contractions/possessives;
- sentence spacing.

Minimal pairs should dominate early training:

```text
helo -> hello
teh -> the
quiet / quite
there / their
```

Use heldout words to test rule transfer rather than memorization.

### L2 — Vocabulary and lexical relations

Purpose: attach meaning and usage to word forms.

Core lesson types:

- definition -> word;
- word -> definition;
- example vs non-example;
- synonym/near-synonym;
- antonym;
- category membership;
- concrete relation (`hammer -> tool`);
- selection from context;
- multiple-meaning disambiguation using the current sentence;
- use a taught word in a constrained sentence.

Example:

```text
CORTEX:
[DEFINITION] A puppy is a young dog. [/DEFINITION]
USER:
What is a puppy?
TARGET SEMANTICS:
young dog
```

Invert later:

```text
USER:
What do we call a young dog?
TARGET:
puppy
```

Then context transfer:

```text
CORTEX:
"The box is enormous."
USER:
Does enormous mean very small, very large, or very quiet?
TARGET:
very large
```

Vocabulary should increasingly come from Axon's own world: canonical, provenance, lineage, checkpoint, rollback, consolidator, substrate, curriculum, transaction, evidence, mask, dormant, proposal, compiler, commit, branch, regression, serialization, etc.

### L3 — Morphology: words changing form

Purpose: learn productive patterns plus exceptions.

Families:

- singular/plural;
- present/past/progressive;
- third-person agreement forms;
- comparative/superlative;
- derivational prefixes/suffixes;
- common irregulars.

Examples:

```text
walk -> walked
play -> playing
box -> boxes
happy -> unhappy
teach -> teacher
```

Then exceptions:

```text
go -> went
child -> children
mouse -> mice
```

Hold out stems so the gate measures rule application.

### L4 — Grammar mechanics

Purpose: teach local sentence structure with objectively checkable tasks.

Families:

- subject/verb agreement;
- tense consistency;
- pronoun reference;
- articles;
- basic prepositions;
- negation;
- question formation;
- conjunctions (`and`, `but`, `because`, `if`, `then`);
- sentence ordering;
- grammatical vs ungrammatical choice;
- repair malformed simple sentences.

Examples:

```text
The dogs [runs / run] outside.
TARGET: run
```

```text
Fix: The dogs runs outside.
TARGET: The dogs run outside.
```

```text
Yesterday I [go / went / going] to the store.
TARGET: went
```

```text
Arrange: the / dog / quickly / ran / home
TARGET: The dog quickly ran home.
```

These are excellent early targets because correctness is much less subjective than open conversation.

### L5 — Structural sentence transformations

Purpose: learn relationships between forms rather than isolated strings.

Families:

- statement <-> question;
- present <-> past;
- singular <-> plural;
- affirmative <-> negative;
- active <-> passive for simple forms;
- two simple sentences -> one coordinated/causal sentence;
- pronoun substitution;
- direct wording -> concise paraphrase with fixed semantic slots.

Example:

```text
Statement: The machine is running.
Question target: Is the machine running?
```

```text
The server stopped.
The disk was full.
Instruction: Join using "because".
Target: The server stopped because the disk was full.
```

### L6 — Reading comprehension

Purpose: build meaning over text while staying grounded in exact evidence.

Progression:

1. one sentence / one fact;
2. two sentences / state update;
3. referent/coreference;
4. temporal order;
5. cause/effect;
6. comparison;
7. two-fact composition;
8. distractors;
9. evidence spread across pages;
10. stale/current contradiction.

Example:

```text
Ben has a red ball.
Ben gives the ball to Mia.
Question: Who has the ball now?
Target: Mia.
```

Then multi-page:

```text
Page 1: Ben has the ball.
Page 8: Ben gives the ball to Mia.
Page 15: Who has the ball now?
```

The answer is unchanged, but the capability now requires recurrent complete-field integration.

### L7 — Short composition

Purpose: move from selection/correction to controlled generation.

Progression:

- write a sentence containing a required word;
- write a sentence matching required semantic slots;
- combine two facts;
- answer in one sentence;
- explain in two sentences;
- summarize a short passage;
- produce a three-sentence paragraph with topic/support/conclusion;
- rewrite for clarity without changing required facts.

Early composition should have validators based on required semantic content and structural constraints rather than one exact wording.

### L8 — Dialogue and conversational acts

Purpose: return to C1-like tasks after lower-level language competence exists.

Families:

- greeting;
- acknowledgement;
- grounded answer;
- clarification;
- accepting correction;
- uncertainty admission;
- turn-taking;
- concise explanation;
- following explicit style/length instruction;
- referring correctly to previous turn;
- responding to disagreement without inventing evidence.

This band should absorb the corrected version of C1 rather than compete with it.

### L9 — Axon-domain language and technical literacy

Purpose: make language study progressively identical to the work Axon will perform.

Use real governed Axon concepts and later real evidence:

```text
canonical
provenance
checkpoint
lineage
rollback
consolidator
substrate
field
rail
Soul
mask
Dormant
transaction
regression
commit
branch
compiler
exception
timeout
serialization
```

Exercises:

- define from examples;
- choose the correct usage;
- distinguish related terms;
- explain one mechanism in one sentence;
- read a small verified repo fact and answer a question;
- compare two exact concepts;
- correct a stale statement using newer canonical evidence.

Language education then becomes domain education without abandoning the language gates.

### L10 — Procedural/engineering language

This is where Kimmy's engineer-session harvest and the Curriculum Foundry become major sources, after credential-safe import.

The core learns to read and communicate engineering episodes:

```text
problem -> inspection -> evidence -> action -> tool result -> correction -> test -> report
```

But the Schoolhouse should reach this band only after basic reading, grammar, comprehension and composition demonstrate competence.

## 5. The most important target change: validators, not one sentence everywhere

The existing C1 audit exposed a fundamental issue: `PROCESS_EVIDENCE` authored conversation strings are currently being consumed as exact supervised targets by the unchanged harness.

That must be corrected before the Language School becomes a serious capability experiment.

Different lesson types require different target semantics.

### Target class A — Exact transport target

Appropriate for:

- spelling;
- exact copy;
- punctuation repair with one intended result;
- categorical word choice;
- fixed morphology answer;
- typed region/operation/address/EOS mechanics.

Validator: exact categorical/Unicode payload.

### Target class B — Deterministic structured target

Appropriate for:

- multiple choice;
- identify noun/verb category if explicitly taught;
- select correct tense;
- choose referent;
- factual answer with one canonical slot/value.

Validator: canonical class/slot/value, while surface wording may vary if the answer is emitted as text.

### Target class C — Semantic-content target

Appropriate for:

- grounded short answers;
- vocabulary definition;
- two-fact comprehension;
- constrained paraphrase;
- short composition.

The manifest should describe required and forbidden semantic atoms, for example:

```text
required:
  - value: 40
  - unit: liters
forbidden:
  - value: 20
```

or a canonical fact identity plus accepted textual realizations for early campaigns.

Do not require one exact sentence when several wordings are equally correct.

### Target class D — Process/quality evidence only

Appropriate for subjective open conversation such as a friendly greeting or stylistic response when no objective validator exists.

These examples may:

- provide distributional exposure;
- be used in non-gradient evaluation;
- become supervision only after explicit human endorsement or later outcome evidence under the existing evidence-qualified contracts.

They must NOT silently receive exact-response gradient weight merely because an engineer wrote a plausible sentence.

### Immediate Codex requirement

Before a clean next C1/Language campaign, Trainer loading/loss construction must enforce teaching eligibility and target-validator type. `PROCESS_EVIDENCE` must not accidentally become exact supervised gold.

Also isolate curriculum-family metrics. A declared C1/Language heldout decision may not be diluted with a mechanism heldout case unless the contract explicitly defines a composite metric.

## 6. Child-like study method: spiral curriculum and spaced repetition

The analogy to human schooling is useful in pedagogy, not as a claim that neural development equals a child's brain.

Use a **spiral curriculum**:

```text
learn
 -> recognize
 -> recall
 -> transform
 -> use in context
 -> revisit after delay
 -> use under distraction
 -> use in a novel task
```

Example for vocabulary word `ephemeral`:

1. visible definition + choose meaning;
2. word -> definition;
3. definition -> word;
4. choose correct sentence usage;
5. same word after other lessons;
6. definition removed; retrieve from the core's learned state/Soul context where doctrinally appropriate;
7. apply in a technical phrase such as `ephemeral storage`;
8. distinguish general meaning from a current field-specific definition.

Example for `because`:

1. recognize the word;
2. choose which pair has cause/effect;
3. fill the blank;
4. join two provided sentences;
5. write a new constrained sentence;
6. use naturally in a later explanation.

Each reappearance should increase transformation distance rather than repeat the identical input/target pair.

## 7. Soul curriculum: learning, memory and continuity must be distinguishable

The Schoolhouse is an excellent place to test whether private Soul becomes useful rather than decorative.

However, we must distinguish three mechanisms:

1. **parameter learning** — what the brother learns across optimizer steps;
2. **current-field evidence** — what is visible right now;
3. **private Soul continuity** — what this particular brother carries causally across phases/ticks.

Design explicit Soul-relevant lesson chains.

### Example: short-term vocabulary continuity

Tick 1:

```text
CORTEX: "ephemeral" means temporary or short-lived.
USER: Which word means temporary?
```

Heart commits the completed turn; the same core's Soul advances.

Tick 2:

Remove the definition from the current field and ask a controlled recall question.

Compare:

- correct carried Soul;
- zeroed HOT Soul;
- irrelevant same-core Soul fixture where legal;
- stale Soul;
- correct field evidence restored.

A Soul-relevant case should measurably degrade under the relevant ablation.

### Current-field authority case

Soul carries an old general understanding. Current exact field supplies a narrower definition or correction. Correct behavior must use the current field.

Thus the core learns both:

```text
Soul can help continuity
```

and:

```text
Soul is not canonical authority
```

Never fabricate autobiography such as "I learned this yesterday" merely because a training fixture taught a word. The candidate's actual experience of taking the lesson is its lived trajectory; historical material remains study material.

## 8. Multi-page scaling: pages are difficulty, not context ceilings

Language lessons should gradually increase transport length while preserving exact complete-field coverage.

Suggested progression:

```text
1 short page
2 pages
3-6 pages
8-16 pages
32+ pages
large Dormant-derived passages later
```

Do not make those numbers architectural limits.

A reading-comprehension case can have identical semantic difficulty while varying transport distance. This gives a clean measurement of page/recurrent-state scaling.

Example family:

```text
Fact A at beginning
Fact B at end
question after both
```

Variants:

- adjacent facts;
- one distractor paragraph;
- several pages apart;
- order reversed;
- stale conflicting fact before current fact;
- relevant fact removed (must abstain/admit uncertainty).

Report performance versus page count and evidence distance.

```text
Gate 005 past tense regular

Gate 015 short sentence generation
Gate 016 sentence combination
Gate 017 delayed vocabulary recall
Gate 018 Soul-relevant recall differential
Gate 019 proposal-use language case

```

A typical small gate could begin around:

```text
20-50 train

5-10 regression/counterfactual
```

but these are campaign budgets only. The manifest records actual counts; no silent truncation; future campaigns may grow arbitrarily.

A useful session shape:

```text
warm-up/review

 -> immediate practice
 -> mixed practice
 -> one counterfactual
 -> one delayed review item
```

Trainer should be able to schedule by competency mastery, not merely loop linearly over a monolithic corpus.

## 10. Advancement rules: what counts as mastering a gate

Loss reduction alone is insufficient.

Each gate should declare its own measurable task metric and baseline before training.

Examples:

- spelling repair: exact word accuracy;
- morphology: unseen-stem rule accuracy;
- grammar choice: classification accuracy vs strongest constant answer;
- grammar repair: exact/structured correction rate;
- vocabulary: required semantic-slot accuracy;
- reading comprehension: answer fact/value accuracy;
- uncertainty: correct abstain/uncertainty rate when evidence is absent;
- current-field authority: corrected-current answer vs stale answer rate;
- Soul continuity: correct-Soul minus ablated-Soul differential;
- proposal society: correct grounded proposal adoption / stale proposal rejection;
- generation: valid Unicode/EOS rate plus semantic validator pass;
- long field: accuracy as evidence distance/page count grows.

Every campaign must report:

- train metric;
- heldout metric;
- regression metric;
- strongest trivial/constant baseline;
- free-running output validity;
- exact transport health;
- field/Soul/proposal counterfactual dependence where applicable;
- forgetting of previously passed gates.

A gate should not open the next level merely because teacher-forced loss is lower.

## 13. Controlled counterfactual generator

Real validated lessons should seed synthetic controlled variants.

For each eligible lesson, generate changes that isolate one capability:

### Orthography

- one letter substituted;
- one letter omitted;
- transposed pair;
- capitalization changed;
- punctuation removed.

### Vocabulary

- definition swapped with near-but-wrong meaning;
- irrelevant definition injected;
- word used in a different sense;
- synonym/antonym contrast.

### Grammar

- subject number changed;
- tense cue changed;
- pronoun antecedent changed;
- sentence word order perturbed.

### Evidence

- relevant fact removed;
- similar-but-wrong fact inserted;
- stale fact placed before corrected fact;
- provenance broken;
- cause/outcome order reversed.

### Soul

- correct Soul;
- ablated relevant layer;
- stale same-core Soul fixture under existing legal/test contracts;
- irrelevant Soul context.

### Brothers

- correct proposal;
- confident stale proposal;
- malformed proposal;
- conflicting proposals;
- larger brother wrong / smaller brother grounded right.

Every derived case must be marked derived and inherit the source lineage split.

## 14. Brother society should enter language school gradually

Early L0-L4 lessons can be single-core/simple-board to reduce confounds.

Later bands should deliberately reintroduce society.

Examples:

```text
Brother A says "run".
Brother B says "runs".
Field: "The dogs ___ outside."
Candidate must choose grounded grammar, not majority/size/confidence.
```

```text
Brother A answers from stale history.
Brother B cites current field correction.
Candidate consolidator must use current evidence.
```

```text
D512 brother is confident but wrong.
D64 brother has exact current evidence.
Correct consolidator follows evidence.
```

This prevents social deference from becoming a substitute for language/evidence competence.
