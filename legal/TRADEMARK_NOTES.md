# Trademark Notes — "Axon"

Version 1.0 — 2026-08-31
Nothing here is legal advice; trademark practice is attorney territory. This
file exists so Jeff knows the landscape before spending anything.

## The honest problem with "Axon" as a software name

"Axon" is a **descriptive-common term in the AI/neuro space** — it's the
neural connection metaphor, and it is heavily used:

- **Axon AI** — enterprise contract-intelligence AI company (established).
- **Axon (formerly TASER)** — the body-camera/evidence company; publicly
  traded (AXON); aggressively trademark-enforced, including against
  companies using "Axon" in tech contexts.
- **Axon Framework** — a well-known Java event-sourcing/CQRS framework
  (axonframework.org) — directly in software.
- Numerous AI/neuroscience papers, products, and startups use "axon" as a
  common word.

**Practical consequence:** the name "Axon" for an AI memory/state product is
weak as a trademark (hard to register in class 9/42 for AI software given
the prior users) and carries collision risk with the enforceable Axon
Enterprise brand. This is a *name-strategy* issue, not a project-blocking
one — the code, IP, and priority are unaffected.

## Options (for Jeff to consider with an attorney, when it matters)

1. **Keep "Axon" internally, launch under a different public name.**
   Cheapest, zero conflict. The repo/name stays as-is; a product name is
   chosen at publication time. Common pattern.
2. **Coined/descriptive-hybrid name** for the public project (e.g., anything
   unique enough to register in class 9/42 for "AI memory software"), with
   "Axon technology inside" style description.
3. **Use "Axon" publicly anyway** — viable only if Jeff accepts: no strong
   registration, no enforcement ability against other "axon" users, and a
   non-trivial chance of a cease-and-desist from Axon Enterprise (which has
   litigated the name). Not recommended for a commercial path.
4. **Buy/negotiate** — not realistic here.

## What trademark protects (vs. copyright vs. patent)

| Right | Protects | Axon status |
|---|---|---|
| Copyright | The actual code (this repo) | Automatic; Jeff's already |
| Patent | The mechanisms (see disclosures) | Unfiled; provisionals optional |
| Trademark | The *name/logo* in commerce | Not acquired; "Axon" is weak/conflicted |
| Trade secret | Anything unpublished | Active (repo is private) |

## If/when a public name is chosen

- Search first: USPTO TESS (tmsearch.uspto.gov) + a general web/CRISPER
  search for the exact name in software classes. Free to do.
- U.S. common-law rights begin on *use in commerce*; federal registration
  (TEAS, $250/class) makes enforcement real. Register the moment a public
  product exists under the name.
- **Do not** spend on registering "Axon" itself for this project without
  attorney sign-off on the conflict question.

## Recommendation (engineer's view, for what it's worth)

Do nothing now. The project is private; trademark only matters in commerce.
When Stage 0 of the readiness checklist (public-launch decisions) happens,
choose a distinct public name at that time, and keep "Axon" as the internal
project identity — the way many products ship under names different from
their repo codenames.
